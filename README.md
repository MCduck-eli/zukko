## 🇺🇿 O'zbek Tilida

### 🚀 Loyiha Haqida
**Zukko** — bu talabalar va o'quvchilarga turli fanlardan imtihon testlarini topshirishda yordam beradigan platforma. Oddiy test tizimlaridan farqli ravishda, bu yerda **Sun'iy Intellekt (AI)** assistent vazifasini bajaradi:
* **Xatolar tahlili:** Test yakunida xato javoblaringizni tahlil qiladi.
* **Tushuntirish:** Qayerda va nima sababdan xato qilganingizni batafsil tushuntirib beradi.
* **Yo'naltirish:** Bilimingizdagi bo'shliqlarni to'ldirish uchun aynan qaysi mavzularni yoki manbalarni qayta o'qib chiqish kerakligini tavsiya qiladi.

### 🛠 Texnologiyalar
* **Frontend:** HTML, CSS, JavaScript / React.js
* **Backend:** Python / Node.js
* **AI Integratsiyasi:** OpenAI API / Gemini API
* **Ma'lumotlar bazasi:** PostgreSQL / MongoDB / SQLite
